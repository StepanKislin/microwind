Install

MicroWind не требует build-процесса. В базовом сценарии достаточно подключить один CSS-файл.

Local file

Локальное подключение

Подходит для статических сайтов, прототипов, лендингов и HTML-макетов.

<link rel="stylesheet" href="./microwind.css">
HTTPS

Подключение через GitHub Pages

После деплоя CSS можно использовать как внешний ресурс по HTTPS.

<link rel="stylesheet" href="https://stepankislin.github.io/microwind/microwind.css">

Principles

Идея библиотеки: каждый класс делает одно предсказуемое действие. Вместо написания кастомных компонентов ты собираешь интерфейс из коротких utility-слоёв.

Atomic composition. Комбинируй `.flex`, `.gap-4`, `.p-6`, `.rounded-2xl`, `.shadow` и получай готовый блок.
Zero build. Всё работает как обычный CSS-файл, без npm, PostCSS, Sass или bundler.
Readable naming. Имена классов близки к привычным utility-framework паттернам и легко читаются прямо в HTML.

Spacing

В `v1.1` spacing-система стала заметно полнее: теперь удобно контролировать и внутренние, и внешние отступы, а также интервалы между соседними элементами.

Padding, Margin, Space

Ниже показаны основные группы spacing-классов.

Group Examples Use case
p-* p-4 px-6 py-8 Внутренние отступы карточек, контейнеров, кнопок
m-* mt-4 mb-8 mx-auto Вертикальные отступы между секциями и центровка блоков
space-* space-y-4 space-x-2 Быстрый ритм внутри списков и горизонтальных рядов
-m* -mt-4 -ml-2 Небольшие перекрытия, декоративные смещения, badge-overlap

Layout

Библиотека покрывает типовые layout-сценарии: flex, grid, widths, heights, alignment и container-like ограничения через `max-w-*`.

Flex row

Grid columns

Colors

MicroWind использует набор переменных `--mw-*` и готовые `bg-*`, `text-*`, `border-*` классы. Для мягких UI-акцентов доступны специальные варианты вроде `bg-blue-10` и `bg-emerald-10`.

Blue
.bg-blue .text-blue
Indigo

Emerald

Orange

Responsive

В библиотеке есть набор `sm:*`, `md:*`, `lg:*` модификаторов для layout, spacing и typography. Этого достаточно, чтобы без отдельного CSS делать адаптивные секции и сетки.

Пример responsive-шаблона

<section class="grid grid-cols-1 md:grid-cols-2 gap-6 px-4 md:px-12 py-8">...</section>
