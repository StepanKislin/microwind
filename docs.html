Install

MicroWind не требует build-процесса. В базовом сценарии достаточно подключить один CSS-файл и сразу получить расширенный utility-набор для display, layout, spacing, sizing, position, surfaces, colors, typography, filters и states.

Local file

Локальное подключение

Подходит для статических сайтов, прототипов, лендингов и HTML-макетов.

<link rel="stylesheet" href="./microwind.css">
HTTPS

Подключение через GitHub Pages

После деплоя CSS можно использовать как внешний ресурс по HTTPS.

<link rel="stylesheet" href="https://stepankislin.github.io/microwind/microwind.css">

Principles

Идея библиотеки: каждый класс делает одно предсказуемое действие. Вместо написания кастомных компонентов ты собираешь интерфейс из коротких utility-слоёв.

Atomic composition. Комбинируй `.flex`, `.gap-4`, `.p-6`, `.rounded-2xl`, `.shadow` и получай готовый блок.
Zero build. Всё работает как обычный CSS-файл, без npm, PostCSS, Sass или bundler.
Readable naming. Имена классов близки к привычным utility-framework паттернам и легко читаются прямо в HTML.

Typography

Типографика в MicroWind строится из небольших composable-классов: размеры, веса, line-height, tracking, alignment и шрифтовые семьи. В `v1.4` набор стал заметно богаче за счёт `font-serif`, `font-extrabold`, `text-9xl`, `antialiased`, `subpixel-antialiased` и `line-clamp-*`.

Filters

В `v1.4` доступны filter и backdrop-filter utilities для более атмосферных интерфейсов: `blur-*`, `brightness-*`, `contrast-*`, `grayscale`, `invert`, `sepia`, `saturate-*`, `backdrop-blur-*`, а также вспомогательные ring и shadow surface-утилиты.

Element filters

Фильтры применяются прямо к элементу и помогают быстро менять восприятие декоративных блоков и медиа-плейсхолдеров.

.blur-sm .brightness-110 .contrast-125 .saturate-150 .sepia

Backdrop filters

Backdrop utilities размывают фон позади панели. Это удобно для sticky navigation, floating cards и overlay-блоков.

.bg-white .backdrop-blur .border .border-fuchsia .contrast-125

Soft glass card

Комбинируй backdrop blur с полупрозрачным фоном и контрастом для более дорогого визуального ощущения.

Практический совет: фильтры лучше использовать как акцент, а не как базовый стиль на всех элементах. Чаще всего достаточно одного `backdrop-blur` блока и 1-2 декоративных filtered-элементов в hero или карточке.

Composition

Самый быстрый способ работать с MicroWind: мыслить не компонентами, а слоями. Сначала выбирай display/layout, затем spacing, потом цвет, типографику и только после этого добавляй state или filter utilities.

Recommended order

1. Structure: .flex .grid .table .w-full
2. Rhythm: .p-6 .gap-4 .space-y-3
3. Surface: .bg-white .border .rounded-2xl .shadow
4. Tone: .text-slate .font-extrabold .bg-sky-10
5. Interaction: .hover:bg-blue .transition-colors .backdrop-blur
