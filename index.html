Что стало лучше

Больше полезных классов без потери простоты

Библиотека осталась маленькой и понятной, но теперь удобнее покрывает реальные сценарии: карточки, hero-блоки, бейджи, кнопки, панели, списки и базовые адаптивные секции.

↕

Spacing-system

Добавлены более полные `m-*`, `mx-*`, `my-*`, `mt-*`, `mb-*`, `ml-*`, `mr-*`, а также отрицательные отступы и `space-x / space-y` для списков и рядов.

◫

Размеры и layout

Теперь есть больше ширин и высот, фракционные значения вроде `w-1/2`, `w-3/4`, дополнительные `max-w-*`, позиционирование и расширенный grid/flex-набор.

✦

States и декор

Появились `transition-colors`, новые hover-варианты, фоновые soft-цвета, простые градиенты, `bg-clip-text`, анимация `animate-float` и улучшенные тени.

Документация

Готовые комбинации классов

Ниже не абстрактные названия, а реальные наборы utility-классов, которые можно сразу копировать в проект.

.flex .items-center .justify-between .gap-4 .p-6

Подходит для navbar, header-строк и тулбаров.

.space-y-4 .p-6 .rounded-2xl .bg-white .shadow

Удобно для карточек с вертикальным стеком элементов.

.mx-auto .max-w-4xl .px-6 .py-12 .grid .md:grid-cols-2

База для responsive hero или двухколоночной секции.

.border .border-blue .text-blue .hover:bg-blue .hover:text-white

Outline-кнопки и secondary CTA без отдельного компонента.

Подключение

Скачать файл или подключить по HTTPS

Для GitHub Pages нужен только деплой репозитория. После публикации этот же `microwind.css` будет доступен по прямой HTTPS-ссылке.

1. Скачать локально

Скачай файл и положи рядом со своим HTML или в папку `assets/css`.

<link rel="stylesheet" href="./microwind.css">
Скачать `microwind.css`

2. Подключить через GitHub Pages

После деплоя используй прямую ссылку на CSS. На опубликованном сайте она сформируется автоматически.

<link rel="stylesheet" href="https://stepankislin.github.io/microwind/microwind.css">
