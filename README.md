# MicroWind CSS

**Утилитарная CSS-библиотека нового поколения**  
Минимализм, производительность и полный контроль. Просто добавляйте классы в HTML — никакой магии, сборки или JS.

## 📦 О проекте

MicroWind — это атомарный CSS-фреймворк, вдохновлённый идеями Tailwind CSS, но с фокусом на **минимальный размер**, **человекопонятные имена классов** и **нулевой порог входа**. Весь фреймворк — это один файл `.css` без единой строчки JavaScript. Подключайте его и начинайте строить интерфейсы как из кубиков LEGO.

Проект включает в себя демо-лендинг с **живой песочницей**, где можно экспериментировать с классами в реальном времени.

---

## ✨ Особенности

- **⚡ Нулевой оверхед** — чистый CSS, не требует сборки, препроцессоров или зависимостей. Размер ~4KB в gzip.
- **🧩 Атомарная композиция** — каждый класс делает одно предсказуемое действие (`.flex`, `.justify-center`, `.gap-4`).
- **🎨 CSS-переменные** — легкая кастомизация через `:root`. Меняйте цвета, отступы, радиусы и тени без перекомпиляции.
- **🖱 Интерактивность из коробки** — псевдоклассы (`.hover-scale`, `.hover:bg-blue`, `.transition-all`) работают без JS.
- **📱 Адаптивность** — базовые отступы и сетка легко масштабируются.
- **🛠 Живая песочница** — на лендинге встроен редактор HTML с мгновенным превью.
